## Brand Identity & Design System

### Color Tokens

| Token | Value | Semantic Role |
|---|---|---|
| **Ink** | `#1A1816` | Warm near-black charcoal for typography, dark panels, and structural elements |
| **Parchment** | `#EFE8DA` | Warm ivory baseline canvas |
| **Bone** | `#FAF7F0` | Archival card surfaces, visual plate mounts, and elevated contrast areas |
| **Oxblood** | `#6B2333` | Signature accent used with restraint (primary CTAs, key accent dividers) |
| **Brass** | `#A6813C` | Antique metallic accent for filigree lines, badges, and guild marks |
| **Stone** | `#8C8577` | Muted neutral for subtitles, technical parameters, and metadata |

### Typography Pair
- **Headlines & Editorial Quotes**: `Newsreader` (Google Fonts, editorial serif loaded via `next/font/google`).
- **Body & UI Controls**: `Work Sans` (Google Fonts, geometric sans loaded via `next/font/google`).

### Architectural Layout Principle
Asymmetric split layout evoking bespoke invitation folios rather than generic SaaS layouts. Lower-third text positioning, generous negative space, refined hairline borders, and zero cliché badges or arrows.

## Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/Yashsoni7978/Ember-Ivory-Events.git
cd Ember-Ivory-Events

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the live site.

---

## Production Build & Vercel Deployment

```bash
# Verify static production build
npm run build

# Run production server
npm run start
```

### Deploy to Vercel
1. Import repository on [Vercel](https://vercel.com/new).
2. Framework Preset: **Next.js**.
3. Zero environment variables required. Click **Deploy**.
